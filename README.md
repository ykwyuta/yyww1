# 欧州大戦 1914–1919

Rust で作った Age of Empires 風のリアルタイムストラテジーです。**ブラウザ版**（WebAssembly）と **Windows 版**（Direct3D11 / Direct2D）があり、ゲームの中身は共通です。
[ykwyuta/yyempire](https://github.com/ykwyuta/yyempire)（春秋戦国 — 中華統一への道）のエンジン（シミュレーション・AI・UI・記録・描画層）をそのまま流用し、
舞台を第一次世界大戦の欧州に移しました。WebAssembly にコンパイルし、描画は WebGL2 と Canvas2D。外部クレートは使っていません。

ブラウザ版は静的サイトとして Cloudflare（Workers の静的アセット／Pages）で公開できます。Windows 版は [ykwyuta/yyempire-win](https://github.com/ykwyuta/yyempire-win) と同じ作り（`windows` クレートだけで描画・入力・UI を自作）です。

**ドキュメント**：紹介とユーザーガイド（[日本語](docs/ja/introduction.md)・[English](docs/en/introduction.md)・[中文](docs/zh/introduction.md)）。

## 遊ぶ・ビルドする

WebGL2 に対応したブラウザで、公開したサイトを開くだけで遊べます。

```
bash build.sh                      # Rust が無ければ rustup で導入し、dist/ に静的サイトを出力
cd dist && python3 -m http.server 8000
```

ブラウザで http://localhost:8000/ を開く。

### Windows 版

```
cargo run --release --bin yyww1-win
```

Windows で `cargo build --release --bin yyww1-win` とすると `target/release/yyww1-win.exe` ができる（アイコンは `build.rs` が埋め込む）。GitHub Actions の `windows` ジョブでも exe を作って成果物（yyww1-windows）に上げる。

- 描画は Direct3D11（地形・図形）と Direct2D／DirectWrite（文字・UI）。文字が小さいときは Ctrl＋＋／Ctrl＋−、F11 で全画面。
- 表示言語は `%APPDATA%\yyww1\settings.txt` に保存する（初回は Windows の表示言語に合わせる）。
- 記録は `%APPDATA%\yyww1\saves\slot{N}.yysav`。ブラウザ版と同じ形式なので、「書き出す」「ファイルから読み込む」で行き来できる。
- 異常終了の調査ログは `%APPDATA%\yyww1\logs\` に残る。

### Cloudflare への公開

- **Workers（静的アセット）**：`bash build.sh && npx wrangler deploy`（設定は `wrangler.toml`）
- **Pages／Workers Builds（Git 連携）**：ビルドコマンド `npm run build`（中身は `bash build.sh`）、出力ディレクトリ `dist`

`dist/` は `index.html`・`main.js`・`yyww1.wasm` などだけで、画像などの素材は wasm に埋め込まれている。

## ゲームの特徴

- **舞台**：1914年6月28日（サラエボ事件）〜1919年6月28日（ヴェルサイユ条約の日）。地図は欧州・大西洋・北米の東海岸・トルコ（小アジアと中東）・ウラル山脈まで（大西洋の中ほどは縮めて描く）。ライン・ドナウ・ヴォルガ・ドニエプル・マルヌ・ソンム・ピアーヴェなどの河川、アルプス・カルパティア・カフカス・ウラルなどの山脈を再現。
- **20か国**：ドイツ・オーストリア＝ハンガリー・オスマン帝国・ブルガリア（同盟国）、イギリス・フランス・ロシア・セルビア・ベルギー（協商国）、イタリア・ルーマニア・ギリシャ・ポルトガル・アメリカ（のちに参戦）、オランダ・スイス・スペイン・スウェーデン・ノルウェー・デンマーク（中立国）。**プレイヤーは米国を選べない**。
- **史実の同盟と都市**：同盟国と協商国の同盟関係は最初からある。各国には史実の都市（ベルリン・パリ・ペトログラード・コンスタンティノープルなど約200）が最初からあり、**新しい都市は築けない**。
- **開戦は自動**：サラエボ事件から七月危機の宣戦布告（オーストリア→セルビア、ドイツ→ロシア・フランス・ベルギー、イギリス→ドイツ……）までは史実の日付に自動で起こる。オスマン帝国・イタリア・ブルガリア・ポルトガル・ルーマニア・ギリシャも史実の日付に参戦する。陣営どうしの和睦はない。中立国に宣戦すると、その国は敵の陣営に加わる。
- **勝利と天使**：同盟国以外の国（参戦した敵国）をすべて打ち破れば勝利。1919年6月までに勝者が現れなければ天使が降り、半年のうちにすべての都市を占領してゲームオーバー。
- **生産と資源は開戦時がもっとも豊か**：生産力は戦争が長引くほど下がり（1919年に約55%）、森・鉱山は掘るほど減る。開戦時の蓄えは大国ほど多い。
- **兵は民から徴兵する**：民と兵を合わせた人口には上限があり、兵営で兵を1人訓練するたびに民が1人減る。軍を大きくすれば経済は細る。動員解除で兵を民に戻すこともできる。
- **世論**：戦場での損失が相手より多い、人口に対して兵が多すぎる（軍事費が重い）、食糧が尽きた、都市を失った……といった状況が続くと世論が下がる。**帝政の国（ドイツ・オーストリア・オスマン・ロシア・ブルガリア）では世論が尽きると革命が起きて降伏**し、都市は敵国に明け渡される。民主制の国では革命は起きないが、ストライキで生産が落ちる。
- **国ごとに造れる兵種が違う**：歩兵・砲兵・騎兵はどの国も造れる。戦車（英国1916年9月〜・フランス1917年4月〜・米国1918年〜）、突撃兵（ドイツ1916年7月〜）、山岳兵（イタリア・オーストリア・フランス・スイス）、Uボート（ドイツ・オーストリア）、駆逐艦（英・仏・伊・露・米）。
- **兵器は兵を割り当てて造る**：戦車は兵5人、Uボートは4人、駆逐艦は6人を選んで割り当てる（戦車は自国の領内で、軍艦は自国の軍港のそばで）。兵は兵器に変わり、兵には戻せない。兵器の能力は乗った兵の能力の平均。
- **海を渡る**：海の向こうへ兵を動かすと、兵は港で輸送船に乗って渡り、目的地に近い港や海岸に上陸する。
- **植民地と Uボート**：英国・フランスには植民地（カナダ・インド・アフリカ・アルジェリアなど）と米国から船で資源と民が届く。Uボートはこれを沈め、駆逐艦は Uボートを狩る。
- **米国の参戦**：米国は中立。中立の米国の船を沈められるなど「妨害」を受けて参戦気運が 100 に達したときだけ、協商国側で参戦する。ドイツは「無制限潜水艦作戦」を始められる（ドイツの AI は史実どおり1917年2月に始める）。
- **塹壕陣地**：近づく敵兵を撃ち、そばの味方の損害を減らす。自国の領内で守る兵も損害が少なく、戦線は膠着しやすい。
- **史実の出来事**：マルヌの奇跡・毒ガス・ルシタニア号・ヴェルダン・ソンム・ブルシーロフ攻勢・ツィンメルマン電報・春季攻勢・スペインかぜなど37件（記録はゲーム内の「戦史」F3）。
- **国の特徴**：プロイセン参謀本部、ロイヤル・ネイビー、75mm野砲、ロシアの蒸気ローラー、ガリポリの守り、アルピーニ、英国の海上封鎖など、史実に基づく特徴。
- 春秋戦国版から引き継いだもの：戦場の霧、指揮中は時が止まる、建設の予約、訓練・教化による能力の強化、記録（セーブ・ロード）、チュートリアル、三言語（日本語・英語・中国語）、タッチ操作。

操作はゲーム内の F1（ヘルプ）を参照。F2 外交、F3 戦史、F4 戦況、F5 記録。

## 記録（セーブ・ロード）

F5（または画面右上の「記録 F5」）で記録画面を開く。3枠の手動記録と、3か月ごとの自動記録がある。記録はブラウザの IndexedDB に保存される。
「書き出す」でファイル（.yysav）にし、「ファイルから読み込む」で再開できる。

## 構成

| ファイル | 内容 |
|---|---|
| `src/geo.rs` | 地理データ（海岸線・河川・山脈・湖）、20か国と約200の史実の都市、地形生成 |
| `src/world.rs` | シミュレーション：ユニット・建物・経済・戦闘・陣営と宣戦 |
| `src/world/naval.rs` | 海上：兵の渡海、植民地と米国からの船団、Uボートによる撃沈と米国の参戦気運 |
| `src/world/opinion.rs` | 世論と革命（帝政の国の降伏） |
| `src/world/history.rs` | 史実年表（七月危機・参戦・戦い・疫病）と君主家・政体 |
| `src/world/traits.rs` | 国ごとの特徴と、国ごとに造れる兵種 |
| `src/world/descent.rs` | 天使の降臨（1919年6月までに勝者が現れなかったとき） |
| `src/world/save.rs`・`src/save.rs`・`src/game/save.rs` | 記録の読み書き |
| `src/ai.rs` | コンピュータ国家の思考（局所的に優勢なときだけ攻め、劣勢なら前線の都市で守る。Uボートと駆逐艦） |
| `src/game.rs` | 画面、入力、HUD、外交・ヘルプ画面 |
| `src/game/status.rs` | 戦況画面（各国の世論・損害、海上の情勢） |
| `src/game/chronicle.rs` | 戦史画面 |
| `src/game/tutorial.rs` | チュートリアル（フランスで開始） |
| `src/art.rs`・`src/gfx.rs` | アイコン・UI の生成と描画層（WebGL2 / Canvas2D） |
| `src/i18n.rs`・`src/lang.rs` | 三言語の切り替えとデータの訳 |
| `tools/import_generated_art.py` | ImageGen製の国別軍装・兵器・建物アトラスをPNG／前乗算BGRAへ変換 |
| `assets/sources/` | 採用した生成元画像、生成プロンプト、再取り込み手順と史実表現の範囲 |
| `tools/gen_art.py` | 旧手続き生成素材（復元する場合のみ `--legacy-overwrite` を指定） |
| `web/` | ブラウザ側（index.html・main.js） |
| `src/main.rs`・`src/win/app.rs` | Windows 版の実行ファイルと、Win32 の窓・メッセージループ |
| `src/win/gfx.rs` | Windows 版の描画層（Direct3D11 / Direct2D / DirectWrite） |
| `src/win/platform.rs` | Windows 版の記録・設定の置き場所（%APPDATA%\yyww1）とファイルダイアログ |
| `src/win/crashlog.rs` | Windows 版の異常終了の調査ログ |
| `build.rs` | Windows 版の exe にアイコンを埋め込む |

## テスト

```
cargo test --release
```

```
cargo test --release long_sim -- --nocapture
```
